## 🚀 Ejecutar localmente

1. Cloná el repositorio:
```bash
git clone https://github.com/MatiasVirga/portafolio.git
cd portafolio
```

2. Abrí `index.html` directamente en tu navegador, o usá Live Server en VS Code.

> No requiere `npm install` ni ningún proceso de build.
