## 🚀 Ejecutar localmente

1. Cloná el repositorio:
```bash
git clone https://github.com/MatiasVirga/portafolio.git
cd portafolio
```

2. Abrí `index.html` directamente en tu navegador, o usá Live Server en VS Code.

> No requiere `npm install` ni ningún proceso de build.

## 📦 Proyectos incluidos

### ⚡ AutomatizaHoy — Marca y plataforma de servicios
El paraguas donde convergen todos los proyectos. Empaqueta los trabajos sueltos (Barber Fort, Citroën, automatizaciones de planillas) en una oferta concreta para PyMEs: sitios que venden, procesos que se hacen solos y agentes de IA que atienden. Landing de una sola página con casos reales, demos en vivo, comparador antes/después de un Excel reconstruido de cero y contacto directo por WhatsApp.

**Stack:** HTML/CSS/JS · n8n · Google Apps Script · Netlify (build propio)

🌐 [automatizahoy.com.ar](https://automatizahoy.com.ar)

### 💈 Barber Fort — Sistema de Reservas Online
Sistema de autogestión de turnos para cadena de barberías premium. Elimina ~50 mensajes de WhatsApp por día, reserva en menos de 60 segundos, costo operativo $0/mes.

**Stack:** HTML/CSS/JS · Google Apps Script · Google Sheets · Netlify
